Pocket Jinn wake-word model
===========================

These five files are the verified files from the official sherpa-onnx release
archive:

  https://github.com/k2-fsa/sherpa-onnx/releases/download/kws-models/
  sherpa-onnx-kws-zipformer-gigaspeech-3.3M-2024-01-01.tar.bz2

The encoder comes from that full release archive. The encoder in the separate
"-mobile" archive is smaller but fails on the first decode with a Reshape
shape error in sherpa-onnx 2.0.3, so the full int8 encoder is bundled here.

The keyword tokens for "HEY JINN" were produced with the official sherpa-onnx
text2token tool using this same bpe.model:

  sherpa-onnx-cli text2token \
    --tokens tokens.txt \
    --tokens-type bpe \
    --bpe-model bpe.model \
    keywords_raw.txt keywords.txt

Result:

  ▁HE Y ▁ J IN N

The app writes that line to keywords.txt beside the copied model files.
